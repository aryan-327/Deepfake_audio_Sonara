# Sonara - Deepfake Audio Detection

Sonara is an advanced acoustic anomaly detection system designed to verify the authenticity of human speech and detect synthetic generation artifacts left behind by deepfake audio models. 

It features a high-performance Python (FastAPI) backend for machine learning inference and a beautiful, highly interactive React (Vite) frontend for real-time analysis and result visualization.

## Features
- **Spectral Analysis:** Analyzes high-frequency spectral artifacts generated by synthetic speech engines.
- **Neural Heuristics:** Uses a machine learning voting ensemble to evaluate vocal tract resonance and phase anomalies.
- **Real-time Processing:** Connects via WebSockets to stream inference logs directly to the user interface in real-time.
- **Interactive UI:** Smooth Framer Motion scroll reveals, parallax backgrounds, and persistent particle motion providing a premium user experience.

## Project Structure


## Getting Started

### 1. Run the Backend (FastAPI)
The backend runs on Python and requires a virtual environment.

```bash
# Navigate to the backend directory
cd backend

# Create and activate a virtual environment
python -m venv venv

# On Windows:
venv\Scripts\activate
# On Mac/Linux:
# source venv/bin/activate

# Install dependencies
pip install -r requirements.txt

# Start the server
uvicorn main:app --port 8000 --reload
```
The backend API will now be running at `http://localhost:8000`.

### 2. Run the Frontend (React)
The frontend requires Node.js (v18+ recommended).

```bash
# Navigate to the frontend directory
cd frontend

# Install dependencies
npm install

# Start the development server
npm run dev
```
The frontend UI will now be running at `http://localhost:5173`. 

## Usage
1. Open the frontend in your browser.
2. Drag and drop a `.wav` file into the upload zone (you can use one of the files from the `test_samples/` folder).
3. Watch the real-time terminal output as the audio is analyzed.
4. View the final confidence score determining if the audio is Authentic (Human) or Synthetic (Spoofed).
